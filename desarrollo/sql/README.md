# SQL — espacio de trabajo pendiente de definición

Esta carpeta se reserva para consultas o scripts de base de datos si el profesor/PO confirma que el proyecto requiere persistencia relacional. No se ha seleccionado un motor y aquí no hay un esquema definitivo.

Antes de crear tablas o consultas, acordar motor y versión, necesidades de las historias, campos autorizados, relaciones, integridad, permisos, respaldo y entorno. No utilizar datos personales reales en ejercicios o demos.

La guía `../Guia_Desarrollo.md` explica la relación entre SQL y persistencia y ofrece una plantilla de consulta sin nombres de tablas ni reglas inventadas.
