# Python — espacio de trabajo pendiente de definición

Esta carpeta se reserva para una posible capa de lógica de servidor. Su existencia no significa que Python, un framework o una API hayan sido seleccionados.

Antes de añadir una implementación, confirmar con el profesor/PO y revisar el sílabo: necesidad funcional, framework y versión, responsabilidades del servidor, endpoints, validaciones, pruebas, autenticación, manejo de datos y despliegue.

El código actual de `prototipado/MVP/` se ejecuta en el navegador y usa almacenamiento local; no es una aplicación Python. `python -m http.server` solo sirve archivos estáticos para probar la interfaz.

La guía de arquitectura y un ejemplo didáctico neutral están en `../Guia_Desarrollo.md`.
