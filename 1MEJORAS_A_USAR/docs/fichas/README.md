# Fichas de control de Sprint

Una ficha por semana con los siete puntos del profesor (nombre del Sprint, objetivo, actividades realizadas, funcionalidades implementadas, problemas encontrados, evidencias de funcionamiento y actividades pendientes) más su lista de control de siete verificaciones. El formato está en `../Guia_Plan_Final_4_Semanas.md`. Nombre de archivo: Ficha_Sprint_X_Semana_Y.md.
