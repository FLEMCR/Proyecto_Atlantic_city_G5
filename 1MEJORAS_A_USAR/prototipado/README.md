# Prototipado

Contiene los tres productos del bloque de diseño de la estructura de entrega, separados para no mezclarlos.

| Punto de la estructura | Contenido |
|---|---|
| 8. Wireframes digitales | `wireframe_manual.png` y `wireframe_digital.png`: la misma pantalla Inicio/Dashboard en boceto manual y en versión digital. |
| 9. MVP | `MVP/`: una sola pantalla con el recorrido mínimo funcional (HTML, CSS y JS separados). |
| 10. Prototipo con navegación | `prototipo_navegable/`: siete vistas conectadas entre sí (HTML, CSS y JS separados, más una versión en archivo único). |

`../docs/Guia_Prototipado_y_MVP.md` explica qué representa cada wireframe, el recorrido del MVP, las vistas del prototipo con navegación, los datos de demostración, los límites y las pruebas manuales de ambos.

Los wireframes no son pantallas implementadas: no tienen botones funcionales, validaciones ni navegación. El MVP y el prototipo con navegación usan datos ficticios guardados en el navegador y no se conectan con sistemas reales. Para ejecutar cada versión, consulta `MVP/README.md` (puerto 4173) y `prototipo_navegable/README.md` (puerto 4174).
