# Diagramas UML

Imágenes de los puntos 12, 14 y 15 de la estructura de entrega. La explicación de cada una —cómo se construyó, cómo se lee y qué no se debe afirmar con ella— está en `../../docs/Guia_Modelado_UML_Atlantic_City.md`.

- `Casos_de_uso.png`: actores y doce casos de uso del alcance actual; HU-13 fuera del límite del sistema.
- `Secuencia_registrar_cliente.png`: recorrido actor → interfaz → sistema → datos al registrar un cliente, con el fragmento alt del identificador.
- `Secuencia_registrar_visita.png`: recorrido al registrar una visita o interacción.
- `Secuencia_evaluar_promocion.png`: recorrido de evaluación de elegibilidad con el fragmento alt «Aplica» / «No aplica».
- `Clases.png`: seis clases con los atributos que usan hoy el MVP y el prototipo, y sus asociaciones con multiplicidades.

Estas imágenes están incrustadas en `../../informe/Avance_Atlantic_City.docx`. Si se redibuja alguna, se reemplaza también dentro del documento para que ambas versiones coincidan.
